Privacy policy#

Last updated: 23 November 2026

Modern Sheet is an application that runs on your device. We have no servers, we collect no personal data, and we use no advertising, analytics or tracking.

Data on your device#

Songs, settings, the library index and the local copy of a synced library stay in the app's data folder on your device. None of this data is sent to us.

Google Drive (optional)#

If you connect Google Drive to sync your library:

  • the app asks Google only for the drive.file permission: it can see and change only the files it creates (the library folder and the songs in it), not the rest of your Drive;
  • you sign in with the code entered at google.com/device; the access token is stored only on your device, in the app's data folder, and is deleted with Disconnect;
  • songs travel directly between your device and your Google Drive, with no intermediary;
  • the app reads your email address only to show which account is connected and to keep the libraries of different accounts apart on the device.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time from your Google Account security page.

chordsheet.com (optional)#

If you import songs from your chordsheet.com account, the email and password are sent only to chordsheet.com to log in. The password is never stored; the email is stored on the device only if you choose Remember the email.

The modernsheet.app website#

The website is hosted by GitHub Pages and uses no cookies or analytics. The Download page asks GitHub (api.github.com) for the details of the latest published version, to show its number and date. GitHub may record technical data about visits (for example the IP address) to run and protect the service: see GitHub's privacy statement.

Contact#

For questions about this policy, open an issue in the project repository.
